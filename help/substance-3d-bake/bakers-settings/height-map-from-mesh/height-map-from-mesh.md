# Mapa de altura da malha

O Mapa de altura do baker de malha permite criar um mapa de altura de uma malha de alta poli.**Disponível em:**

* Painter
* Designer
* Kit de ferramentas de automação

## Parâmetros

| *Parâmetro* | *Descrição* |
| --- | --- |
| **&#x200B;**&#x200B;Normalização&#x200B;**&#x200B;** | Define como o intervalo de valores do height deve ser salvo na textura.Valores possíveis:<ul data-preserve-html="true"><li data-preserve-html="true"><strong>Relativo à distância do raio</strong>:</li><li data-preserve-html="true"><strong>Em relação à malha poli baixa (por Bloco UV)</strong> (padrão)</li><li data-preserve-html="true"><strong>Em relação ao Mín./Máx. (por bloco UV)</strong></li><li data-preserve-html="true"><strong>Manual</strong></li></ul> |
| **Dimensionando divisor** | Defina quanto os valores de height devem ser multiplicados ou divididos.Disponível apenas quando a **Normalização** está definida como **Manual**. |
