# Converter UV para SVG

O Converter UV em SVG transforma os UVs de malha de baixo-poli em um arquivo gráfico vetorial. Esse arquivo gráfico vetorial pode ser usado para criar máscaras.

**Disponível em:**

* Substance Designer
* Substance Automation Toolkit

## Parâmetros

| *Parâmetro* | *Descrição* |
| --- | --- |
| **Preenchimento** | Controla o preenchimento geométrico a ser adicionado às formas de SVG. |
| **Modo de cores** | Define como as formas de SVG devem ser coloridas.Valores possíveis:<ul data-preserve-html="true"><li data-preserve-html="true"><strong>Aleatório:</strong> cada shell UV é colorido por uma cor aleatória.</li><li data-preserve-html="true"><strong>Alteração de MATIZ:</strong> cada shell UV é colorido por um valor de matiz exclusivo.</li><li data-preserve-html="true"><strong>Escala de cinza:</strong> cada shell UV é colorido por um valor de escala de cinza exclusivo.</li><li data-preserve-html="true"><strong>Cor uniforme:</strong> todas as conchas UV são coloridas por um valor de 50% de cinza.</li><li data-preserve-html="true"><strong>Cor de ID de material</strong>: as conchas UV são coloridas pela cor de material definida na Exibição de Cena.</li></ul> |
