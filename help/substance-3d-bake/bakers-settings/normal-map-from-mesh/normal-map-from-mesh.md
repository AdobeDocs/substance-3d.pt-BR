# Mapa normal da malha

O Mapa normal do baker de malha permite criar um espaço tangente ou mapa de espaço de mundo normal a partir de uma malha de poli alto.**Disponível em:**

* Substance Painter
* Substance Designer
* Substance Automation Toolkit

## Parâmetros

| *Parâmetro* | *Descrição* |
| --- | --- |
| **Tipo de Mapa** | Controla que tipo de textura normal o baker deve gerar.Valores possíveis:<ul data-preserve-html="true"><li data-preserve-html="true"><strong>Espaço Mundial</strong></li><li data-preserve-html="true"><strong>Espaço Tangente</strong> (padrão)</li></ul>*No Substance Painter, esse parâmetro não pode ser controlado e está definido como Espaço Tangente.* |
| **Orientação Normal** | Define o formato da textura normal se o parâmetro **tipo de mapa** estiver definido como Espaço tangente.Valores possíveis:<ul data-preserve-html="true"><li data-preserve-html="true"><strong>OpenGL</strong></li><li data-preserve-html="true"><strong>DirectX</strong> (padrão)</li></ul>*No Substance Painter, este parâmetro é controlado pelas [configurações do projeto](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/interface/project-configuration).* |
