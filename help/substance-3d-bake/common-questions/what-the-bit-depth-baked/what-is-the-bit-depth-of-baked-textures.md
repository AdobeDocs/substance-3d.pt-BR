# Qual é a profundidade de bits das texturas assadas?

>[!WARNING]
>
> **Pergunta**
> 
> Qual é a profundidade de bits das texturas assadas?

>[!NOTE]
>
> **Solução : Substance Designer**
> 
> A profundidade de bits depende do formato de arquivo de destino usado para salvar as texturas.

>[!NOTE]
>
> **Solução : Substance Painter**
> 
> As saídas do padeiro são geradas como texturas RGBA de 16 bits. A profundidade de bits final depende do formato de arquivo de destino usado para salvar as texturas. O formato de arquivo de 32 bits converte as informações de entrada de 16 bits, mas não obtém mais precisão.

>[!NOTE]
>
> **Solução : Kit De Ferramentas De Automação De Substance**
> 
> A profundidade de bits depende do formato de arquivo de destino usado para salvar as texturas.
