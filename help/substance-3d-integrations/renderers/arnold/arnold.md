# Arnold

O material de superfície padrão em Arnold 5 agora suporta o fluxo de trabalho metálico. É possível exportar os canais de documento do Substance Painter ao usar o sombreador metálico padrão ou ao usar simples as saídas de fluxo de trabalho metálico do plug-in de Substance de um material de Substance.

* Cor de base
* Rugosidade
* Metálico
