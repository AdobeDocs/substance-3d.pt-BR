# Redshift

O material do Redshift na versão 2.5.43 é compatível com o fluxo de trabalho metálico. Para renderizar com o Redshift, você pode usar mapas exportados do Substance Painter ou o plug-in Substance no [Maya](https://www.substance3d.com/ecosystem-plug-ins/substance-in-maya/).

O Substance Painter 2020.1 (6.1.0) é enviado com o Redshift ([rsMaterial](https://docs.redshift3d.com/display/RSDOCS/Material)) [Modelo de saída](https://docs.substance3d.com/display/SPDOC/Export), bem como uma saída herdada para o Redshift 3.
