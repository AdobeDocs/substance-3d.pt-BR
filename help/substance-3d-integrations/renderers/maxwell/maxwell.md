# Maxwell

Para renderizar com o [Maxwell](https://maxwellrender.com/), você pode usar mapas exportados do Substance Painter ou o plug-in Substance no [Maya](https://www.substance3d.com/ecosystem-plug-ins/substance-in-maya/).

O Substance Painter 2020.1 (6.1.0) é fornecido com os [Modelos de saída](https://docs.substance3d.com/display/SPDOC/Export) Maxwell para metálicos/rugosidade e speculares/brilho para uso com o **Maxwell 5.1.0**.
