# Maya 2.1.7

Lançado em 28 de setembro de 2020

Alterar lista:

* Atualizado para ser compatível com o Substance Engine v.8.0.3, oferecendo suporte a novos nós adicionados no Designer 2020.2

Esta versão foi lançada para o Maya 2017, 2018, 2019 e 2020 no Linux, MacOS e Windows, e para o Maya LT 2018, 2019 e 2020 no MacOS e no Windows
