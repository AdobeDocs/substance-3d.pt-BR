# Maya 2.2.3

Alterar lista:

* Adicionado suporte para Arnold 7.1.0/MtoA 5.1.0 para Maya 2019, 2020 e 2022
* Adicionado um novo comando de script, &#39;substanceNodeGetGraphMetadata&#39;, para adquirir os metadados do gráfico de Substance como uma sequência de caracteres XML no script
* Consultar um gráfico fora dos limites em chamadas de script não trava mais
* Os plug-ins Arnold e MtoA agora são instalados em um diretório usando delimitadores &#39;-&#39; entre números de versão semântica
* As configurações de recursos do mecanismo agora são respeitadas corretamente, corrigindo uma regressão em que foram ignoradas.

1. 2.3 é lançado para
1. Maya 2017, 2018, 2019, 2020, 2022 e 2023 no Linux, macOS e Windows
1. Maya LT 2018, 2019 e 2020 no macOS e no Windows
