# Maya 2.4.0

<b>Adicionado/Atualizado:</b>

* Atualização do mecanismo de Substance para a versão 9 no plug-in Maya, aprimorando o desempenho e a compatibilidade.

<b>Corrigido:</b>

* Correção de um problema crítico no Maya 2023 em que a criação de uma rede com arquivos sbsar a partir do mecanismo de Substance versão 9 ou anterior causava falha no aplicativo, garantindo uma criação de rede estável com esses arquivos.

O Maya 2.4.0 foi lançado para Maya 2020, 2022 e 2023 no Linux, macOS e Windows
