# Maya 2.1.3

Lançado em 17 de junho de 2020

Hoje, lançamos a versão 2.1.3 do plug-in.

2.1.3 Versão:

* O instalador agora está assinado com SHA-256 no Windows
* Todos os binários dentro do instalador agora estão assinados no Windows
* substance\_link.dll e substance\_portal\_cli.dll agora têm informações de versão/descrição no Windows
* Adicionada uma opção de fluxo de trabalho para a superfície padrão no Maya 2020

Esta versão foi lançada para o Maya 2017, 2018, 2019 e 2020 no Windows, Linux e Macos. Também foi lançado para o Maya LT 2018, 2019 e 2020 no Windows e no MacOS.
