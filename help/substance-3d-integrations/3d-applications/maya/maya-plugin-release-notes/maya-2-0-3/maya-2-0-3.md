# Maya 2.0.3

A versão 2.0.3 do plug-in agora está disponível no [site](https://www.substance3d.com/ecosystem-plug-ins/substance-in-maya/).

Alterações:\
\* O fluxo de trabalho de RVay agora define o Material de Vray para usar a aspereza\
\* Alguns links para o novo site substance3d foram atualizados.\
\* Adicionada a versão do Substance Engine ao menu Sobre\
\* Comandos de script adicionados para consultar a versão do Substance Engine\
\* A entrada $pixelsize não trava mais\
\* As entradas de valor definidas no Designer agora são visíveis no nó, como as entradas de imagem\
\* O script de fluxo de trabalho Redshift agora define brdf como ggx e o nó de relevo para usar normais de espaço tangente\
\* Novo script de fluxo de trabalho Renderman para melhor corresponder ao uso esperado\
\* O comando substanceSetWorkflow agora aceita corretamente um argumento de sequência de caracteres\
\* Suporte adicionado para o Maya 2020

Atualmente, a versão 2.0.3 está disponível para o Maya 2018, o Maya 2019 e o Maya 2020 no Windows, MacOS e Linux. Também foi lançado para Maya LT 2018, Maya LT 2019 e Maya LT 2020 no Windows e MacOS.
