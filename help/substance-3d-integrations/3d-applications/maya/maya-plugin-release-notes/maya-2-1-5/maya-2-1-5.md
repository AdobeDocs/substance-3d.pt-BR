# Maya 2.1.5

Lançado em 5 de agosto de 2020

Alterar lista:

* Os arquivos sbsar agora devem ser exibidos e podem ser definidos no editor de caminho de arquivo
* Os caminhos de arquivo devem ser definidos pelo Maya relativo ao compartilhar um projeto
* Enviar para do Substance Launcher agora copiará o arquivo sbsar para o diretório do projeto

Esta versão foi lançada para o Maya 2017, 2018, 2019 e 2020 no Linux, MacOS e Windows, e para o Maya LT 2018, 2019 e 2020 no MacOS e no Windows
