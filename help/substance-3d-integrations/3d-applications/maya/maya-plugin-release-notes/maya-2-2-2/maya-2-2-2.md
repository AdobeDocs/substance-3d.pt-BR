# Maya 2.2.2

Alterar lista:

* Substance 3D Remote Engine atualizado para 8.4.2
* Suporte adicionado ao Maya 2023
* Adição de suporte para Arnold 7.1.0/MtoA 5.1.0 no Maya 2023
* O fluxo de trabalho do Arnold usando “aplicar fluxo de trabalho a mapas” agora identifica corretamente o mapa “metalness” no modelo do Painter Arnold
* Se você aplicar uma predefinição, os menus suspensos de resolução agora serão atualizados corretamente
* O comando &#39;substanceRunImageWorkflow&#39; agora retornará o sombreador final que foi criado
* O comando &#39;substanceNodeApplyWorkflow&#39; também retornará o sombreador final criado
* O comando &#39;substanceUtilityCreateAndLoad&#39; agora retornará o substanceNode criado

1. O 2.2 foi lançado para o Maya 2017, 2018, 2019, 2020, 2022 e 2023 no Linux, macOS e Windows
