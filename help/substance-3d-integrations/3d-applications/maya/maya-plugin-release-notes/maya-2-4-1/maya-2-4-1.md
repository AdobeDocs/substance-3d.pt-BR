# Maya 2.4.1

<b>Adicionado/Atualizado:</b>

* O plug-in do Maya agora utiliza a GPU por padrão, melhorando significativamente o desempenho e a velocidade de renderização.

<b>Corrigido:</b>

* Correção do link no menu Sobre o Substance do plug-in Maya para redirecionar para a página de notas de versão adequada, agora apontando corretamente para https://helpx.adobe.com/substance-3d-integrations/3d-applications/maya/maya-plugin-release-notes.html.
* Correção de um problema no plug-in Maya em que o valor de resolução exibido não era atualizado na interface do usuário após redefinir um material, garantindo que todos os valores, incluindo a resolução, agora fossem redefinidos corretamente para os estados padrão.

O Maya 2.4.1 foi lançado para Maya 2020, 2022 e 2023 no Linux, macOS e Windows
