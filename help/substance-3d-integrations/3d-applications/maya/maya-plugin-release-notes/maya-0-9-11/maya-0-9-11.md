# Maya 0.9.11

**Alterações do Maya 2.0:**\
**Estabilidade**:

* Os atributos dinâmicos do gráfico agora são criados de forma nativa, não por meio do código do editor de atributos
* Os nós de Substance podem ser criados em lote à medida que são inicializados sem precisar de entrada de interface
* Editor de atributos e editor de propriedades significativamente mais estável
* O desempenho da memória foi significativamente aprimorado, o suficiente para permitir saídas de 8k no mecanismo de GPU
* As configurações/preferências agora são salvas como um arquivo de configuração separado que pode ser facilmente editado fora do Maya

**Script**:

* API de script forte, com qualquer operação desde a obtenção de informações de entrada, gráfico e saída até o carregamento de pacotes sbsar, alteração de gráfico e execução de qualquer operação predefinida no gerenciador de predefinições
* Código de interface do usuário projetado para usar as mesmas funções da API pública de script

**Recursos Substance**:\
**Suporte predefinido:**

* As predefinições incorporadas definidas no designer são carregadas no gerenciador de predefinições
* Importar e exportar arquivos sbsprs, incluindo várias predefinições
* Gerenciador de predefinições
* Suporte Ao Engine V7
* Já funciona com o novo mecanismo de Substance a ser lançado com o Designer 2019.1
* As saídas numéricas são renderizadas para um atributo de saída maya no
* Nó de gráfico/substância, que pode ser conectado a outros nós na hipersombra

**Sistema de fluxo de trabalho:**

* Novos fluxos de trabalho para Arnold, Renderman, VRay, Corona e muito mais
* Extensões de fluxo de trabalho personalizadas em Python
* Inverter os scripts de fluxo de trabalho a partir do hipersombreamento, configurar um fluxo de trabalho personalizado uma vez e salvá-lo
* Usar um fluxo de trabalho com mapas de imagem do Substance Painter

Aprimoramentos de **UI e UX:**

* File -> import .sbsar cria um nó substance
* Arraste e solte arquivos sbsar do navegador de arquivos para o hypershade para criar nós substance 2
* Os atributos agora são definidos pelas categorias definidas no Designer

**Outras melhorias:**

* As entradas de imagem agora funcionam com nós de procedimento
* Agora é possível definir a taxa de amostragem para nós de procedimentos para que seja possível reduzir ou aumentar a amostra de entradas de imagens de procedimentos
* Os nós de saída agora exibem informações de saída codificadas em Substance Designer
* os nós Substance/graph agora podem exibir informações gráficas (autor, etc.)
* Suporte a substituição de camada, como substituições de conexão e substituições de atributo
* O cache para disco escolhe o tipo de arquivo exr para quaisquer saídas HDR, que são saídas com saídas de 16 bits, 16 flutuantes ou 32 bits flutuantes
* Reflexo do plug-in antigo
* Carregar uma cena com o novo plug-in converterá os nós de gráfico e saída antigos em nós do substance 2
