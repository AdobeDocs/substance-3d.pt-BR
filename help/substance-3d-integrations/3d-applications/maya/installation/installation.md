# Instalação

O plug-in Substance no Maya também é instalado oficialmente no instalador do Maya 2022/2020. Ela está ativada para instalação por padrão.

>[!NOTE]
>
> **Maya 2022**
> 
> **Windows**: C:\Program Files\Allegorithmic\Adobe Substance 3D para Maya\2022\
> **MacOS**: /Applications/Allegorithmic/Adobe Substance 3D para Maya/2022\
> **Linux**: /opt/Allegorithmic/Adobe Substance 3D para Maya/2022

>[!NOTE]
>
> **Maya 2020**
> 
> **Windows**: C:\Program Files\Allegorithmic\Adobe Substance 3D para Maya\2020\
> **MacOS**: /Applications/Allegorithmic/Adobe Substance 3D para Maya/2020\
> **Linux**: /opt/Allegorithmic/Adobe Substance 3D para Maya/2020

Além disso, o instalador das versões mais recentes do plug-in pode ser baixado da página [Adobe Substance 3D para Maya](https://substance3d.adobe.com/plugins/substance-in-maya/).
