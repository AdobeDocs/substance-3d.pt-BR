# Aplicar Fluxo De Trabalho A Mapas

Você pode usar **Aplicar fluxo de trabalho a mapas** para aplicar rapidamente texturas exportadas do Substance 3D Painter ou de qualquer aplicativo de pintura a um material no Maya.

A opção **Fluxo de trabalho** permite escolher com qual renderizador você está trabalhando, como Arnold.

![](../../../assets/applymaps.png)

Use **Selecionar Vários Mapas** para selecionar vários mapas a serem aplicados com base na convenção de nomenclatura listada à esquerda. *Por exemplo, a \_aspereza será mapeada para o canal de aspereza.*

Mapas individuais podem ser adicionados clicando no botão de pasta e selecionando a textura.
