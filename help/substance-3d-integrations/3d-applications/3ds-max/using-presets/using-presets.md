# Utilização de predefinições

Os arquivos Substance podem conter arquivos predefinidos incorporados. Se um Substance tiver um arquivo de predefinição incorporado, ele será exibido na janela Predefinições de Substance. Você também pode criar suas próprias predefinições com base nas configurações escolhidas para os Parâmetros Substance.

![](../../../assets/max9.png)

1. Criar predefinição criará uma nova predefinição com base nas configurações de parâmetro que você tiver definido para o Substance no 3ds Max.
1. Importar predefinição importará um arquivo de predefinição (.sbsprs).
1. Salvar predefinição salvará os valores de parâmetro para a predefinição atualmente selecionada.
1. Exportar predefinição selecionada exportará a predefinição para o arquivo de predefinição (.sbsprs).
1. Remover todas as predefinições removerá as predefinições na lista de predefinições.
1. Remover predefinição selecionada removerá apenas a predefinição selecionada.
