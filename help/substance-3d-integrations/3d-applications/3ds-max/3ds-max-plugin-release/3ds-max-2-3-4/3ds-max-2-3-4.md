# 3ds Max 2.3.4

Lançado em 16 de junho de 2020

1. 3.4 Versão:

* Adição da opção de fluxo de trabalho para o sombreador PBR (Spec/Gloss) para 3ds Max 2021
* Adição da opção de fluxo de trabalho para o sombreador PBR (Metal/Bruto) para o 3ds Max 2021
* Os scripts de fluxo de trabalho não falham mais ao mover nós entre diferentes exibições no SME
* A definição de um caminho relativo no controlador de ativos agora funcionará
* Se uma saída esperada por um script de fluxo de trabalho estiver ausente, ela será registrada no console
* Adicionado Sobre a caixa de diálogo, contendo informações sobre o plug-in, juntamente com bibliotecas usadas.
* A caixa de diálogo Sobre tem um botão “Copiar para área de transferência”, como Substance Painter, Substance no Maya ou o Iniciador de Substance, permitindo que as informações de diagnóstico sejam salvas.

Esta versão foi lançada para o 3ds Max 2018, 2019, 2020 e 2021.
