# 3ds Max 2.3.3

Lançado em 3 de junho de 2020

Hoje nós lançamos a versão 2.3.3 do plugin, que é uma versão de correção de bugs sobre 2.3.2.

2.3.3 Versão:

* Arquivo de plug-in renomeado de SubstanceMax.dlt para substancemax.dlt
* Informações de versão e descrição adicionadas a substance\_link.dll
* Corrigido um problema com a versão de verificação do redshift que agora deve funcionar com o Redshift 3
* Correção de uma falha ao desfazer/refazer após carregar um sbsar no nó do substance
* Regressão corrigida com caixa de diálogo de configurações não funcionando
* Correção de uma falha ao carregar um arquivo sbsar que contém caracteres não latinos

Nosso pipeline de lançamento também foi completamente refeito, então você deve ser capaz de esperar lançamentos muito mais frequentes, em comparação com os maiores, muito distantes que fizemos no passado.

Esta versão foi lançada para o 3ds Max 2018, 2019, 2020 e 2021.
