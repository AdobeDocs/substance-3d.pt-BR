# 3ds Max 2.4.1

Lançado em 18 de dezembro de 2020

**Adicionado:**

* Atualizado para ser compatível com o Substance Engine v.8.0.3, oferecendo suporte a novos nós adicionados no Designer 2020.2
* Editar a exportação predefinida para exportar todas as predefinições selecionadas (várias exportações)

**Corrigido:**

* O substance\_link.dll está consumindo um grande número de ciclos de CPU
* Erro de asserção ao exportar uma predefinição de Substance
* Falha ao criar uma predefinição quando não há nenhuma
* Falha com o denoiser para o renderizador Corona

Esta versão foi lançada para o 3ds Max 2019, 2020 e 2021
