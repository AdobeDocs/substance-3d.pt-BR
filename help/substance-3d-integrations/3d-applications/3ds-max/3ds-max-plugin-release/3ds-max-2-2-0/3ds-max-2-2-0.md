# 3ds Max 2.2.0

Lançado em 4/06/2019

* Suporte adicionado para o 3ds Max 2020
* Atualizado para o Substance Engine V7, adicionando suporte para processadores de valor do Designer 2019.1
* O plug-in agora carrega os mecanismos do Substance em relação a si mesmo
* Alterar para o formato MSI, instalação/desinstalação silenciosa adequada por meio das ferramentas da Microsoft
* O instalador e os arquivos agora estão assinados corretamente
* O instalador não modifica mais nenhum arquivo do plug-in original
* Correção de um problema em que o menu não era carregado no 3ds Max 2019 (e 2020)
* Foi adicionado suporte nativo ao renderizador ART
* Corrigido um problema com o script de fluxo de trabalho Corona quando não havia saída brilhante
* Os scripts de fluxo de trabalho agora são distribuídos como arquivos .ms simples e podem ser inspecionados
* Alterações cosméticas menores e melhorias de estabilidade
