# Modo Instalação

Para instalar o plug-in, basta arrastar o arquivo LPK para o MODO. Se você não instalou um kit ou o pacote de conteúdo MODO, pode ser apresentado um diálogo solicitando que você crie as pastas apropriadas. Depois que o kit for instalado, você verá um botão Substance no canto superior direito da interface do MODO.
