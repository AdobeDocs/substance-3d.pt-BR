# Animação de Substance

## Animação do SubstanceTextures

Os parâmetros avançados podem ser animados como qualquer outro canal no MODO. Se você estiver usando a variável Substance Engine Time ($time) para animar uma substância, poderá acessar essa variável específica do mecanismo nos Canais do Usuário para o Substance.\
Ao animar esse canal, você pode gerar animações se o Substance for criado usando a variável $time.
