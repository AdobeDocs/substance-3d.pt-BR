# Configuração

## Requisitos

É necessário o Cinema 4D R16 ou superior. Todas as versões do produto, exceto o Cinema 4D, são compatíveis.

Os arquivos Substance podem ser criados usando [Substance Designer](https://www.allegorithmic.com/products/substance-designer).

## Instalação

## Windows

1. O Cinema 4D não deve estar em execução durante a instalação.
1. Execute o pacote de autoinstalação.
1. Escolha / verifique a pasta de destino. Essa deve ser a pasta na qual o Cinema4D foi instalado, não a subpasta de plug-ins.
1. Clique em Instalar.
1. Após a instalação bem-sucedida, você terá a opção de iniciar o Cinema 4D.

## MAC OS X

1. O Cinema 4D não deve estar em execução durante a instalação.
1. Solte o arquivo cld na pasta Cinema 4D plugins.
1. Inicie o Cinema 4D, como de costume.
