# Desinstalando o complemento

Para desinstalar o complemento, navegue até Editar > Preferências > Complementos e expanda a seção do complemento.

1. Primeiro remova as ferramentas de integração com o botão **Desinstalar ferramentas**.
1. Em seguida, remova os arquivos do complemento com o botão **Remover**

>[!NOTE]
>
> Se for necessário remover manualmente as Ferramentas de integração do Substance, exclua a pasta Substance3DIntegrationTools do diretório a seguir
> 
> * **Windows**: C:\Users\(username)\AppData\Roaming\Adobe
> * **Mac**: /Users/(nome de usuário)/Library/Application Support/Adobe/Substance3DIntegrationTools
> * **Linux**: /home/(nome de usuário)/Adobe/Substance3DIntegrationTools
