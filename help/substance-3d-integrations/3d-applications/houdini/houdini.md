# Houdini

>[!NOTE]
>
> Substance em Houdini é desenvolvido pela SideFX Labs.

O [Plug-in Substance para Houdini](https://www.sidefx.com/tutorials/sidefx-labs-substance-plugin/) permite carregar arquivos de Substance (SBARs) no Houdini em COPs. Isso lhe dá a capacidade de encadear nós de Substance juntos, alimentar a saída de gráficos de Substance para todas as partes de Houdini (Terrenos, Materiais, Geometria) e muitos outros fluxos de trabalho. O plug-in é mantido pela equipe do SideFX Labs.

## Instruções de instalação

Para Houdini 17.5 o plugin é distribuído com o GameDevelopment Toolset\
[Instruções de Instalação do GameDevelopment Toolset](https://www.sidefx.com/tutorials/game-dev-toolset-installation/)

Para Houdini 18.0 o plugin é distribuído com a SideFX Labs.\
[Instruções de Instalação dos Laboratórios SideFX](https://www.sidefx.com/tutorials/sidefx-labs-installation/)
