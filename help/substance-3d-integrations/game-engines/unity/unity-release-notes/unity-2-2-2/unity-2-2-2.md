# Unity 2.2.2

## 2.2.2 Notas de versão

**data de lançamento: 11/2/2019**

### Plug-in de núcleo:

* Correção de um erro em que a GUI de textura padrão do Unity estava sendo substituída quando o plug-in Substance In Unity foi instalado
  * Correção de um bug em que EditorApplication.delayCall sendo definido causava problemas com outros plug-ins
  * Correção de uma falha que ocorria ao usar caracteres não latinos em um nome de projeto
