# Unity 2.5.4

Lançado em 9 de dezembro de 2020

Corrigido:

* Não é possível gerar aplicativos da iOS compatíveis com código de bits quando os materiais de Substance estão incluídos em um projeto do Unity

Problemas conhecidos:

* Não é possível baixar ativos do Source no Unity de forma consistente. Solução alternativa é baixar do [site do Substance Source](https://source.substance3d.com/) e importar manualmente os ativos.
* No momento, o Unity 2020.2 e superior não é compatível
