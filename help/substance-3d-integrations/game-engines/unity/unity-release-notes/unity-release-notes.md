# Notas de versão do Unity

Atualmente, oferecemos suporte ao plug-in Adobe Substance 3D para Unity a partir da versão 3.0.0 do Unity. As versões anteriores do plug-in Substance 3D para versões mais antigas do Unity serão descontinuadas em breve.

**As versões do Unity de 2.2.0 para 2.6.0 serão descontinuadas em breve.**
