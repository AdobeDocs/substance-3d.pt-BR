# Unity 2.5.3

Lançado em 4 de novembro de 2020

Corrigido:

* Falha ao alterar a embalagem do mapa de Specular
* O Mapa de specular não é um Smoothness de embalagem no canal de Alpha no Projeto 3D Padrão
* Falha ao reiniciar projeto HDRP/HRP após excluir a pasta Biblioteca
* Materiais duplicados sem sombreador atribuído e propriedades de material
* Alterações de caractere de fim de linha em arquivos de cena e pré-fabricados.

Problemas conhecidos:

* Não é possível baixar ativos do Source no Unity de forma consistente. Solução alternativa é baixar do [site do Substance Source](https://source.substance3d.com/) e importar manualmente os ativos.
