# Unity 3.0.0

Lançado em 27 de junho de 2021

Atualizado/adicionado:

* Suporte ao Apple Silicon
* Novo tutorial do YouTube sobre como usar o plug-in
* Nova documentação de scripting
* Suporte a control-z no editor de Gráficos do Substance e no editor principal de arquivos do substance
* Desempenho aprimorado ao carregar um grande número de arquivos sbsar
* Suporte para materiais do Substance com vários gráficos
* Alterada a interface para gerenciar gráficos de Substance
* API exposta para carregar uma predefinição por meio de C#
* Documentação online atualizada

Corrigido:

* Erro na exibição do inspetor ao pressionar o botão aleatório várias vezes
* Entradas de textura nula quebrando atualizações de Substance
* Os alternadores “Gerar todas as saídas”, “Gerar mapas de mip” e “Somente tempo de execução” não funcionam
* Problemas com os Namespaces
* Erro de referência nula ao entrar no modo de reprodução com o ativo do gráfico selecionado
* Problema com HDRP e URP para a versão LTS 2021.3 mais recente do Unity ao usar materiais apenas em tempo de execução
* Problemas de desempenho com arquivos sbsar com várias entradas
* Erros de “O identificador já foi liberado”
* Problema para “entrar no modo de reprodução com a cor azul deslocada”
* O problema do mapa de heights com os arquivos sbsar
* Ocorreu um problema com as entradas de imagem que leem texturas ilegíveis

Problemas conhecidos:

* Correção de um problema do Mac em que os canais R e B das texturas de saída serão invertidos
* Principais aprimoramentos de desempenho para o Mac
