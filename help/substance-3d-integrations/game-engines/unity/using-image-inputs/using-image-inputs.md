# Utilização de entradas de imagem

Para usar uma imagem em um parâmetro de entrada para um Substance:

1. Na janela do inspetor da Gráfico do Substance, você pode selecionar texturas no projeto para atribuir a entradas de imagem.

   ![](../../../assets/imageinput-inspector.png)
1. Observe que selecionar uma textura fará com que o campo de texturas “Leitura/Gravação ativada” seja marcado, pois isso é necessário para ler os dados de textura no material do Substance

   ![](../../../assets/imageinput-texture.png)
