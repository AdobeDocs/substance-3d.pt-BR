# Baixando o plug-in Substance 3D no Unity

## Armazenamento de ativos

O Adobe Substance 3D para Unity está disponível no [Repositório de Ativos do Unity](https://assetstore.unity.com/packages/tools/utilities/substance-3d-for-unity-beta-213208). O plug-in é adicionado ao seu projeto na pasta Ativos.

## Gerenciador de pacotes

Depois de adicionar e baixar o plug-in pelo Repositório de ativos, você pode acessá-lo usando o Gerenciador de pacotes (Unity 2020.3.27x e superior) em **Meus ativos**.

![](https://helpx-prod.scene7.com/is/image/HelpxProd/screen-shot-2022-03-29-at-10-45-20-am?$png$&jpegSize=300&wid=1920)

### Cache do Gerenciador de Pacotes

O cache do Repositório de ativos pode afetar a versão disponível no Gerenciador de pacotes/Meus ativos. Se você não estiver obtendo a versão mais recente, talvez seja necessário excluir o Cache da loja de ativos.\
