# Mecanismos de jogos

Você pode importar um arquivo de Substance (.sbsar) na maioria dos mecanismos principais através do plug-in de Substance.

* O <b>Unity</b> tem o plug-in do substance nativamente integrado para o ciclo de versão 2017. Para o Unity 2018 e superior, o plug-in Substance está disponível no [Repositório de Ativos do Unity](https://assetstore.unity.com/packages/tools/utilities/substance-in-unity-110555).
* O plug-in <b>Unreal Engine</b> pode ser encontrado no [Unreal Marketplace](https://accounts.unrealengine.com/logout?redirectUrl=https%3A%2F%2Fwww.unrealengine.com%2Fmarketplace%2Fsubstance-plugin).
* O plug-in <b>Lumberyard</b> é nativamente integrado.
* O plug-in <b>CRYENGINE</b> é nativamente integrado e mantido pela Crytek. Para obter mais informações, vá para a [documentação do Substance CRYENGINE](https://docs.cryengine.com/pages/viewpage.action?pageId=44968527)
