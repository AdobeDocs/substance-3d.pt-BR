# Imagem de Entrada Substance - UE4

O Substance pode ser criado com entradas nas quais você pode fornecer uma imagem para processamento no material. Isso permite criar materiais modulares que podem receber dados ou padrões de malha cozidos como entrada para alterar ou adequar o material ao ativo. Para usar uma textura como uma entrada de substância, ela deve ser importada para UE4 como uma Textura de entrada de Substance.

1. Importe a textura para o Navegador de Conteúdo. Para o formato, escolha Substance de entrada de imagem (jpg, tga, jpeg).
1. Essa textura agora pode ser usada com uma entrada de Substance.
