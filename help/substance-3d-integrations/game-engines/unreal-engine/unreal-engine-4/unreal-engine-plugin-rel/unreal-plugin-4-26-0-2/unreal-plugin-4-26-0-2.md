# Plug-in irreal 4.26.0.2

Adicionado:

* suporte para Substance Engine v 8.0.3
* A ação Substance Source agora acessa a guia Origem no Iniciador de Substance, permitindo que os ativos sejam enviados diretamente para o UE4 ([mais detalhes](../../../../../game-engines/unreal-engine/unreal-engine-4/source-in-ue4/source-in-ue4.md))
* Número reduzido de materiais de Substance processados ao atualizar versões do projeto

Corrigido:

* O UE4 falha no Mac ao fechar o editor com o plug-in UE4 Substance instalado
* Alterar o parâmetro de texto em uma instância de Gráfico do Substance causa um congelamento e uma eventual falha
