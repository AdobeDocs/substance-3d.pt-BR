# Imagem de Entrada Substance - UE5

Os Substance podem ser criados com entradas nas quais você pode fornecer uma imagem para processamento no material. Isso permite criar materiais modulares que podem receber dados ou padrões de malha cozidos como entrada para alterar ou confirmar o material para o ativo.

* Você pode usar o UTexture2D com uma entrada de Substance.
