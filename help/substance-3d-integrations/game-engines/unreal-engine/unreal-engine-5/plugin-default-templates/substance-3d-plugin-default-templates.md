# Modelos padrão de plug-ins do Substance 3D

*Observação: este recurso está em desenvolvimento no momento e estará disponível em breve.*

Com a versão 5.0.0, introduzimos um fluxo de trabalho de modelo de material renovado *com saídas numéricas suportadas pelo Substance Engine. Os modelos de material permitem que você defina exatamente como deseja configurar os sombreadores de material de Substance em UE5.*
