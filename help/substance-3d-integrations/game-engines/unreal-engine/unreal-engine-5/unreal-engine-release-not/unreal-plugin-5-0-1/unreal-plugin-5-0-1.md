# Plug- in Unreal 5. 0. 1

Atualizado/adicionado:

* Suporte ao Unreal Engine versão 5.0.0+
* Documentação do plug-in Unreal Engine 5
* Suporte para o novo modelo de material Tri-planar
* Suporte para o novo recurso “Tamanho físico”
* *Modelo Padrão de Substance e Modelo de Refração de Substance remodelados*
* A capacidade de modificar o valor da XYZ para o espaço global
* Script Python
* Configurar automaticamente nós de material físico com valores das saídas de substância

Removido:

* O parâmetro float4 no plug-in UE 5

Corrigido:

* O projeto UE5 empacotado trava quando os parâmetros de material são ajustados por blueprints
* O plug-in fecha a janela de parâmetro quando a saída da Instância do Gráfico do Substance está desmarcada
* Correção de um atraso de renderização ocasional que causava alterações de parâmetro atrasadas
